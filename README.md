# 鸡尾酒学社

> **一起学点本事，一起做点有用的事；在力所能及的地方，彼此搭把手。**

你好，欢迎来到鸡尾酒学社。

先说在前面：名字可能有点奇怪，但我们是一个认真的学习与互助社群。我们想做的事情并不复杂------让愿意学习的人有机会接触技术、参与真实项目、积累经验；也让暂时缺少资源、机会或支持的人，能在这里找到一些可以一起尝试的路。

我们不想把这里做成一个由某个人站在讲台上、其他人坐在下面等待指令的地方。发起这件事的人，只是先把门打开、先搭起一个框架。接下来怎么走、能做成什么样，需要每一个愿意参与的人一起探索。

你不必一开始就很厉害，也不必先证明自己值得被帮助。

如果你想学东西，欢迎；如果你有想法，欢迎；如果你会一点技术，愿意和别人一起做个小项目，也欢迎。如果你现在很累、暂时没有精力参与任何事情，也不需要为此道歉。**人不是只有在能提供价值时，才值得被认真对待。**

## 我们为什么想做这件事

有些人并不缺少努力，只是缺少一个入口：没有人带着入门，没有合适的设备或资源，没有机会参与真实项目；也有人因为性别身份、家庭环境、经济状况或其他原因，长期处在不容易被理解和接纳的位置。

我们无法承诺替每个人解决所有困难，也不认为一个社群能代替专业服务或现实支持。但我们相信，学习机会、可靠的信息、一起做事的伙伴，以及公平参与和获得收入的可能性，都可能成为一个人重新积累力量的起点。

过去尝试制作面向跨性别女性的离线工具，也让我更相信：技术不一定只用来追求炫酷或展示能力。它也可以帮助人整理信息、理解自己的处境，并把选择权留在自己手里。

鸡尾酒学社希望延续这种想法：**少一点空泛的承诺，多一点真正能用上的知识、工具、经验和陪伴。**

## 我们希望一起做什么

-   **一起学习：**
    编程、设计、研究、文档、测试、运营，以及其他成员愿意分享的技能。
-   **一起实践：**
    从小工具、开源协作、资料整理到真实需求出发的项目，把知识变成可以使用、展示和继续改进的成果。
-   **一起创造价值：**
    如果项目产生收入，在开始前说清楚参与方式、成本、风险和收益分配；不把"以后可能赚钱"当成保证。
-   **一起互相支持：**
    在各自能力允许的范围内分享经验、信息和资源；有人暂时需要帮助时，尽量让他不必独自面对。
-   **一起成长，也允许各自离开：**
    当你学到了想学的东西、生活有了新的安排，或只是想暂停，都可以自由决定。

我们欢迎跨性别者、处于经济或生活困境的人、曾经被排斥的人，也欢迎任何认同这些原则、愿意平等相处的人。你不需要公开自己的性别身份、家庭经历或其他私人信息，才能加入交流。

## 我们共同遵守的原则

### 1. 自愿参与，不把善意变成义务

学习、项目、捐助、住宿互助和其他支持，都应建立在当事人自愿的基础上。任何人都可以拒绝、暂停或退出，不需要因此受到责备。

### 2. 人的健康比项目进度重要

项目可以延期、缩小、重新分工，必要时也可以停止。我们不鼓励透支身体、牺牲睡眠或把持续加班当作贡献。每个人都应有自己的生活和边界。

### 3. 不涉足黑灰产业

学社不参与黑灰产业，不组织、不承接，也不教授或协助违法和伤害他人的活动。一个项目即使可能赚钱，只要越过这条底线，也不值得做。

### 4. 帮助不附带控制权

接受帮助不代表欠下劳动、服从、忠诚或私人关系上的债务。任何人都不能以提供资源、金钱或住宿为理由，要求别人参与项目、接受管理或满足私人要求。

### 5. 尊重差异与个人边界

不因性别身份、经济状况、能力水平、出身或生活经历歧视他人。不骚扰、不威胁、不欺凌，也不把他人的困难当作谈资或宣传素材。

### 6. 保护隐私

未经本人明确同意，不公开他人的身份、住址、联系方式、健康信息、求助经历或私人聊天记录。请不要因为大家彼此信任，就默认所有信息都可以在群内外传播。

### 7. 规则可以讨论，但底线不能被关系绕过

我们希望通过相处形成默契，也欢迎成员提出改进意见。但遇到资金、劳动、隐私和安全问题时，不能只靠"大家都懂"来处理。亲近不代表可以越界，资历和关系也不应让任何人免于承担责任。

## 关于生活困难与临时住宿互助

学社不是专业救助机构，也不承诺或直接保证任何人的住宿、收入或生活保障。我们不希望把超出能力范围的责任压到某一个热心成员身上。

如果有人确实遇到困难，成员可以在完全自愿的前提下，提供信息、转介资源，或协助有意愿接纳他人的成员与求助者进行**点对点沟通**。是否接纳、住多久、生活安排如何、怎样结束安排，都应由双方自主确认；任何一方都可以拒绝，其他成员也没有必须参与的义务。

涉及住宿时，请认真考虑双方的人身安全、个人空间、隐私和退出方式。不要在公开群聊中发布住址或其他敏感信息。若涉及未成年人、威胁、暴力或其他明显的人身安全风险，不应只靠私下约定处理，应寻求可信赖的成年人或正规服务机构的帮助。

遇到特别紧急的情况，任何成员都可以自愿发起一次集中帮扶，邀请更多人根据自己的能力提供资金、物资、信息或其他支持。发起帮扶不代表其他人有义务响应；涉及资金时，应尽量说明用途、记录收支并反馈结果。

我们能做的是搭起互助的桥梁，而不是承诺每一次都能解决所有问题。**没有能力提供帮助的人，不应因此感到亏欠；正在接受帮助的人，也不需要用劳动或服从来偿还。**

## 关于项目、劳动与收益

学社鼓励自由提案和自愿协作，不以固定职位或在线时长衡量一个人的价值。但自由协作也需要基本的清楚和公平。

每个正式开始的项目，都应尽量提前说明：

-   项目目标、预期成果与参与方式；
-   谁愿意参与、各自准备承担什么；
-   是否涉及成本、风险或对外承诺；
-   代码、设计、文档等成果如何署名、使用和维护；
-   如果项目产生收入，按什么规则分配；
-   如果有人暂停或退出，如何交接。

这些约定应由相关参与者共同讨论，并在投入大量时间之前确认。不能等到项目成功后，才凭印象争论谁贡献更多；也不能因为一个人暂时处境困难，就默认他应当承担更多工作。

提出想法、提供建议、完成开发、测试、整理文档、维护项目等，都可能构成有意义的贡献。不同项目可以采用不同的约定，但应当事先说清楚、尽量透明，并尊重参与者的劳动与选择。

项目可能赚钱，也可能没有收入。我们不会保证每个人都能通过学社获得收入，也不会把潜在收益当作招募他人投入劳动的承诺。参与之前，请先了解项目实际情况，再决定投入多少时间和精力。

## 遇到分歧时

我们不要求所有人意见一致，也不希望每件事都需要某个"负责人"拍板。意见不同是正常的，重要的是把问题说清楚，而不是靠身份、资历、关系或情绪压过别人。

涉及项目时，优先回到事先约定的目标、分工和记录；涉及隐私、骚扰、威胁或人身安全时，应优先保护受到影响的人，并避免让被投诉者单独决定投诉结果。任何规则都可以在实践后讨论改进，但不能用"我们是一家人"要求别人忍受伤害。

## 我们目前还在起步

鸡尾酒学社还在搭建阶段。我们没有假装自己已经解决了所有问题，也不打算一开始就制定一套庞大而僵硬的制度。

有些约定已经明确，有些机制还需要和成员一起讨论，也有些问题只有真正做过项目、经历过协作之后，才能知道怎样处理更合适。

如果你发现了漏洞，欢迎提出；如果你有更好的做法，也欢迎一起补充。我们希望规则不是某个人单方面宣布的答案，而是大家在尊重彼此的前提下，一起建立、检验和改进的共识。

我们也不把留住所有人当作成功。有人在这里学会了一项技能、做出了自己的作品、认识了值得信任的伙伴，之后带着这些能力走向更适合自己的生活------这同样是好事。

## 如果你愿意，可以从很小的一步开始

你可以先看看、先提问、先学一点东西；可以分享一个想法，也可以找一件自己愿意尝试的小事。你不必马上承诺长期参与，不必立刻拿出成果，也不必把自己的困难讲给所有人听。

如果你愿意和我们一起试着做点有用的事，欢迎你。

**愿这里能成为一扇可以推开的门，而不是另一道必须跨过的门槛。**
